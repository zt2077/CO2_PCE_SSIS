# Third-party software and model provenance

The MIT license covers the project scripts and packaging additions. MATLAB, its toolboxes, UQLab, COMSOL, and third-party content retain their own licenses. No MATLAB, UQLab, or COMSOL application code is redistributed here.

The bundled COMSOL model is an author-modified model whose embedded metadata identifies the COMSOL `carbon_dioxide_storage` example for the Johansen Formation. It is preserved byte-for-byte and is not relicensed under MIT. Its original GUI labels and embedded metadata are retained. The package translates the MATLAB source comments; it does not edit the binary model.

Model metadata records COMSOL **6.2.0.290** and these license-feature identifiers: `COMSOL`, `SUBSURFACEFLOW`, `STRUCTURALMECHANICS`, `GEOMECHANICS`, and `LIQUIDANDGASPROPERTIES`. A compatible installation with the required features and LiveLink for MATLAB is needed for forward solves. Redistribution of any underlying vendor-provided model content remains subject to its applicable terms.
